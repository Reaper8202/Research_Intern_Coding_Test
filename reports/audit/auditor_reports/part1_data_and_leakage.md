## 2. Findings worth fixing

No blocker.

**Should-fix**

1. (B10) A second val-label reader. `train_baseline.py:102` reads `labels.parquet` without a row filter and scores val (`:119,311,381-385`), while `val_score.py:253-260` claims to be the only reader. Suggestion: give the step-2 baseline the same Arrow-filtered `load_training_data` for fitting and route its val scoring through `val_score.load_val_labels` (or move that evaluation into the bundle); add a test that asserts no other module reads the label file unfiltered.
2. (B10) The LightGBM test base files are produced inside a label-reading process. `lightgbm_final fit` fits on train labels and writes `reports/lightgbm_final/test_predictions_lightgbm_*.csv` in the same run (`lightgbm_final.py:279-283`). Suggestion: let `fit` save boosters and the feature spec only, and produce the val and test CSVs with the existing label-free `predict` subcommand in a separate Makefile step, keeping the current 1e-9 reproduction check.
3. (B12) Commit the presence-vs-outcome numbers the report cites. Add to `reports/dataset/modalities.json` (or a short report): genomics presence 14.2% / 0.55% / 0.56% by split; positives per patient 2.11 vs 1.83; 9/40 targets p < 0.01, mostly an age effect (75 vs 59 years); imaging presence 2.35 vs 1.82 with the brain-pair targets 14.5% vs 0.27%. State that `[DNA]` is effectively train-only and reaches 2 test patients.

**Nits**

4. (A7) Document that the `STOP == anchor midnight` case (blanked by `>=`) is untestable against the test files (no such row; 10 raw train/val rows).
5. (B1) Trim the allowlists to columns that are used (REASONCODE, ENCOUNTER, encounters.Id are read and discarded).
6. (B2) `train_baseline.load_data` should read `COHORT_COLUMNS` only, like `load_prediction_inputs`, so `last_encounter`/`window_end` never enter a model script's frame.
7. (A4) 119 positives (2%) fall on the window-end day. If the organisers use a half-open window, those train/val labels differ from the hidden convention; this touches training labels only. D4 states the choice; the report could quantify it.
